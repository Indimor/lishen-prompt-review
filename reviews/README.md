## 必须优先修的P0问题

1. **说话人错误**
   - SC01-C06：“明明都是拜你所赐”应为女主角。
   - SC01-C07：“痛……但他的力量……”应为女主角。
   - SC04-C05：“你知道怎么离开这里？”应为女主角。
   - SC09-C08：“黎深，这样……一切就结束了吗？”应为女主角。

2. **整卡复制/剧情缺失**
   - SC08-C04复制上一卡，漏掉女主从背后抱住黎深。
   - SC08-C09复制C08，漏掉文明真相和抵达铁门的出场。
   - SC10-C09复制C08，重复时空转场和管理员开门。

3. **动作或空间硬伤**
   - SC02-C03夜间营地与白日荒漠无转场跳变，并重复治疗动作。
   - SC07-C01把露台藤床放进祭坛大殿。
   - SC07-C05同一只右手同时握短剑和金蚀鸟。
   - SC10-C10同时要求“无可读文字”和清晰生成CLOSED/OPEN。

4. **场次结尾必须补全**
   - SC01以金光淹没两人结束，不混入SC02标题。
   - SC08必须让两人抵达沉重铁门，顺接SC09共同踢门。
