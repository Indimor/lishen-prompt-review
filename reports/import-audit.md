# 导入诊断报告

检查对象：`SC01.md`—`SC10.md`

## 结论

当前仓库已导入场次结构与原剧本卡片，但未导入视频提示词 V1 正文。

以 `SC01.md` 为例：

- 存在 `## SC01-C01`—`## SC01-C07`；
- 每张卡都有 `### 对应卡片原文`；
- 每张卡都有 `### 视频提示词 V1` 标题；
- 标题与下一条分隔线之间没有提示词正文。

因此当前真实状态应为：

```text
source_imported = true
v1_imported = false
review_ready = false
```

## 阻断原因

正式审阅要求逐卡对照：

1. 对应原剧本；
2. GLM 完整 V1；
3. 洄光完整 V2；
4. 修改记录。

缺少 V1 时，只能重新创作提示词，不能称为“审阅 GLM V1”。

## 修复方式

重新运行导入程序时，对每张卡写入：

```markdown
### 视频提示词 V1

<完整提示词正文>
```

导入后运行：

```bash
python scripts/validate_review.py
```

只有输出 `PASS` 后，才开始 SC01 的正式 V2 修订。
